# Two Pointers

## Concept

The Two Pointers technique uses two pointers to efficiently
traverse and process arrays or strings.

## Problems Solved

| LeetCode | Problem | Difficulty |
|---|---|---|
| 125 | Valid Palindrome | Easy |
| 344 | Reverse String | Easy |
| 977 | Squares of a Sorted Array | Easy |

## Key Learnings

- Using left and right pointers
- Moving pointers based on conditions
- Applying the technique to arrays and strings
- Reducing unnecessary nested iterations
